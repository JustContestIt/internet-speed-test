# Замер скорости скачивания

Консольный скрипт на Node.js. Делает 10 последовательных запросов к указанному адресу, каждый раз дожидается полного ответа и печатает среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Запуск

Нужен Node.js 18 или новее (проверено на Node.js 22). Зависимостей нет, `npm install` не требуется.

```bash
git clone https://github.com/JustContestIt/internet-speed-test.git
cd internet-speed-test
node speedtest.js https://registry.npmjs.org/typescript/-/typescript-5.4.5.tgz
```

Аргумент один: адрес файла по http или https. Адрес с `?` или `&` нужно взять в кавычки.

Чем тяжелее файл, тем точнее результат. На файлах меньше пары мегабайт время уходит в основном на ожидание ответа, а не на передачу данных, и скорость получается заниженной. Файл из примера весит 5,83 МБ.

## Единицы измерения

| Величина | Единица | Определение |
|---|---|---|
| Скорость скачивания | Мбит/с | мегабиты в секунду, 1 Мбит = 1 000 000 бит |
| Объём данных | МБ | 1 МБ = 1 000 000 байт; общий объём дублируется в байтах |
| Время запроса | мс | миллисекунды |

Скорость выводится в Мбит/с, потому что в этих единицах её указывают провайдеры и спидтесты. Чтобы получить МБ/с, результат нужно разделить на 8.

## Как считается

- **Время запроса** — от отправки запроса до последнего байта тела ответа, по монотонным часам `performance.now()`.
- **Среднее время** — сумма времён всех запросов, делённая на 10.
- **Объём** — сумма байт тела ответа по всем запросам, заголовки не учитываются. Запрос уходит с `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и счёт шёл по байтам, реально переданным по сети.
- **Скорость** — общий объём в битах, делённый на суммарное время всех запросов.

## Что стоит знать о результате

- Время запроса включает ожидание ответа сервера, а у первого запроса ещё и установку соединения (DNS, TCP, TLS). Дальше соединение переиспользуется, поэтому первый запрос обычно заметно дольше остальных.
- Скачивание идёт в одно соединение с одного сервера. Результат показывает скорость до этого сервера и может быть ниже предельной скорости канала.
- При любой ошибке (сеть, код ответа не 2xx, пустой ответ, нет ответа за 60 секунд) скрипт останавливается на первом неудачном запросе и завершается с кодом 1: итог по неполному набору замеров вводил бы в заблуждение.
